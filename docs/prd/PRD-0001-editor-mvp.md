| 항목 | 내용 |

## 1. 배경
모바일 청첩장 서비스는 대부분 "템플릿 고르기 → 칸 채우기" 방식이다. 사진은 많은데 배치·색감 결정이 어려운 사용자와, 처음부터 세세히 만지고 싶은 사용자가 공존한다. 두 집단을 한 제품에서 모두 만족시키는 것이 목표다.

청첩장으로 시작하지만 돌잔치·파티 등 다른 초대장으로 확장해야 하므로, 초기부터 **행사 종류에 독립적인 문서 모델**이 필요하다.

## 2. 목표 / 비목표
**목표**
- G1. 편집기 하나로 청첩장 필수 구성(히어로, 문구, 날짜, 갤러리, 혼주, 찾아오는 길, 계좌번호, 신랑/신부에게 할 말)을 완성할 수 있다.
- G2. 사진만 올리면 3분 안에 그럴듯한 초안이 나온다(쉽게 시작).
- G3. 데스크탑과 모바일 모두에서 **편집**이 가능하다(보기만이 아니라).
- G4. 편집 화면 미리보기 = 실제 하객 화면 (동일 렌더러).

**비목표 (이번 범위 아님)**
- 홈 페이지 본 개발, 로그인, 서버 저장, 공유 링크 발급, 결제

## 3. 사용자 흐름
```
/ (홈 임시) ─▶ /start ─┬─▶ [쉽게 시작] /quick
                      │      1) 행사 종류  2) 사진 업로드  3) 기본 정보  4) 결과(테마 비교)
                      │                                              │
                      ├─▶ [편집기 바로] ─ 행사 종류 선택 ─────────────┼─▶ /editor ─▶ /view
                      └─▶ [이어서 편집] (초안 있을 때) ───────────────┘
```

## 4. 기능 요구사항
| ID | 요구사항 | 우선 |
|---|---|---|
| F1 | 시작 화면에서 쉽게 시작 / 편집기 바로 시작 선택 | P0 |
| F2 | 쉽게 시작: 사진 다중 업로드, 분석 후 히어로·갤러리·테마 자동 구성 | P0 |
| F3 | 쉽게 시작 결과에서 테마 프리셋 비교 후 편집기 진입 | P1 |
| F4 | 편집기: 섹션 목록(순서 변경, 표시/숨김), 섹션별 속성 폼, 실시간 미리보기 | P0 |
| F5 | 문서 설정(주최자·부모·연락처, 일시, 장소) 공통 편집 | P0 |
| F6 | 테마(프리셋, 포인트 색, 글꼴) 편집 | P0 |
| F7 | 반응형: 데스크탑 3단 / 태블릿 2단 / 모바일 탭 | P0 |
| F8 | 자동 저장(IndexedDB) 및 이어서 편집 | P0 |
| F9 | 하객 시점 미리보기 페이지 | P1 |
| F10 | 계좌 복사, 주소 복사, 지도 앱 링크, 전화/문자 버튼 | P1 |
| F11 | 신랑/신부에게 할 말 작성(로컬 데모) | P2 |

## 5. 주요 설계 결정 (ADR 요약)
| # | 결정 | 대안 | 이유 |
|---|---|---|---|
| D1 | 공통 사실은 `core`, 섹션은 표현값만 | 섹션마다 독립 데이터 | 날짜/장소 중복 입력·불일치 방지 |
| D2 | 섹션 타입별 1개, 삭제 대신 숨김 | 자유 추가/삭제 | MVP 복잡도 축소, 숨겨도 데이터 보존 |
| D3 | 히어로 0번 고정 | 자유 배치 | 초대장의 첫 화면은 항상 대표 이미지라는 도메인 관례 |
| D4 | 쉽게 시작은 규칙 기반(밝기·비율·색) | AI/서버 분석 | 서버 없이 즉시 동작, 결과 설명 가능. v2에서 AI 검토 |
| D5 | IndexedDB 저장 | localStorage | 이미지 data URL이 5MB 한도를 쉽게 넘음 |
| D6 | 업로드 이미지 1600px/JPEG 0.82 재인코딩 | 원본 저장 | 저장 용량·렌더 성능 |
| D7 | 지도는 외부 앱 링크 | 지도 SDK 임베드 | API 키·도메인 등록 없이 동작 |
| D8 | 편집 미리보기와 `/view`가 동일 렌더러 | 별도 미리보기 | WYSIWYG 보장 |
| D9 | 외부 UI 라이브러리 미사용, CSS 변수 | MUI/Tailwind 등 | 초대장 테마 변수 주입과 앱 UI를 단순하게 공존 |
| D10 | 모바일 편집기는 하단 탭(구성/편집/미리보기) | 바텀시트 | 좁은 화면에서 폼 입력 공간 최대화, 구현 단순 |

## 6. 성공 기준
- 사진 5장으로 쉽게 시작 → 편집기 진입까지 클릭 10회 이내
- 375px 폭 모바일에서 모든 섹션 편집 가능, 가로 스크롤 없음
- 새로고침 후 초안 복구

## 7. 열린 질문 (다음 PRD 후보)
- 공유 URL 구조와 공개/비공개 정책
- 방명록 비밀글·삭제 권한
- 행사 종류 변경 허용 여부
- 템플릿 마켓(유료 디자인) 여부

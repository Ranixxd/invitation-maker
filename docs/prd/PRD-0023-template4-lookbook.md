# PRD-0023 템플릿4: 룩북 (사진 중심 편집 디자인)

| 항목 | 내용 |
|---|---|
| 상태 | **확정 (스냅샷)** — 이 문서는 수정하지 않는다. 변경은 새 PRD로. |
| 작성일 | 2026-10-19 |
| 관련 헌법 | CONSTITUTION v1.06 (§3.5, §3.6, §4.1, §6.8, §8) |
| 레퍼런스 | 사용자 제공 이미지 1장: 잔디밭 웨딩 사진 3장을 세로로 이어 붙이고, 사진마다 아래쪽 가운데에 영문 한 줄(흰 글자)을 얹은 편집 디자인 |

---

## 1. 요청
템플릿4 제작. 이미지 중심의 편집 디자인 컨셉. 히어로에는 사진을 1~3장 넣을 수 있고, 사진마다 영문 멘트(결혼 명언 같은)를 얹는다. 멘트는 사용자가 고칠 수 있고, 기본 입력값은 운영자가 준다. 글꼴은 전체적으로 얇은 고딕 계열의 깔끔한 느낌.

## 2. 결정
| # | 결정 | 이유 |
|---|---|---|
| D1 | 새 계열 `lookbook` + 새 팔레트 `white`(흰 바탕 · 잉크 · 짙은 올리브 포인트) + 모양 `round`. 템플릿 id `template4`, 이름 `템플릿4` | 섹션 컴포넌트·토큰은 공용으로 쓰고, 계열 CSS로 얇은 글자·장식 없음만 정한다(§3.6) |
| D2 | 새 히어로 `stack`: 사진 1~3장을 **여백 없이 세로로 이어 붙여** 화면 폭에 꽉 채운다. 장수별 사진 비율 1장 3:4 · 2장 4:3 · 3장 3:2(잘라 채움). 사진마다 아래쪽 가운데에 영문 멘트 한 줄(흰 글자, 읽히도록 아래만 살짝 어둡게) | 레퍼런스 구성. 장수가 늘수록 납작하게 해서 전체 높이를 한두 화면 안에 둔다 |
| D3 | 멘트는 `hero.captions[]`(사진 **칸 순서** 기준, 최대 3). 비우면 그 사진엔 멘트를 표시하지 않는다. 편집 폼 `사진 멘트`에 칸마다 입력칸. 사진을 지워 앞으로 당겨져도 멘트는 칸 순서를 따른다 | 멘트는 순서대로 읽히는 문장이라 사진보다 자리에 묶는 게 자연스럽다 |
| D4 | 기본 멘트는 템플릿 값(`heroCaptions`)으로 두고 `applyTemplate`이 히어로 헤드라인처럼 채운다. 문구 원문은 운영자가 준다(받기 전엔 임시 문구) | 요청: "기본 입력값은 우리가 줄거야" |
| D5 | 글꼴은 **Pretendard 하나**, 이 계열에만 얇은 굵기를 연다: 큰 글자(히어로 이름) ExtraLight 200, 멘트·작은 문구·섹션 제목 Light 300, 본문은 Regular 400 유지. 멘트·영문 작은 문구만 자간을 조금 준다. 기울임(가짜 이탤릭) 없음 | 새 글꼴 없이(이미 불러오는 Pretendard에 200·300 포함) 얇은 고딕. 300 미만 작은 글씨는 모바일에서 흐려져 본문은 400 |
| D6 | 사진 아래: 작은 문구(헤드라인, 기본 `THE WEDDING OF`) · 이름(얇게 크게) · 일시·장소 · 재생 바(템플릿 공통 `MusicBar`) | 사진이 주인공이고 정보는 아래에 조용히 |
| D7 | 다른 섹션: 섹션 머리 하트 없음, 종이 질감 없음, 제목 Light 300. 갤러리 `grid`, 예식 일자 `strip` | 편집 디자인의 깨끗한 흰 지면. 장식 이미지는 사용자 제공 전까지 두지 않는다 |

## 3. 범위 밖
- 레퍼런스의 이탤릭 세리프 영문(얇은 고딕으로 대체).
- 히어로 밖 섹션의 사진 위 멘트(갤러리 등).

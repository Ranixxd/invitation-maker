# PRD-0005 UI 단순화: 공통 헤더 · 쉽게 시작 한 페이지 · 디자인 편집 제거

| 항목 | 내용 |
|---|---|
| 상태 | **일부 대체됨 → PRD-0006** (D5 선택 템플릿 표시, 편집기 헤더 구성), **PRD-0019** (포인트 색 편집) |
| 작성일 | 2026-10-13 |
| 관련 헌법 | CONSTITUTION v0.5 (§1.2, 제2장, §3.5, §5.1, §5.5, §6.2, §6.5, §7.1, §8) |
| 대체 | PRD-0004 D7(사진 색 제안), D10 중 편집기 이탈 확인, 쉽게 시작 3단계·결과 화면 |

---

## 1. 배경
PRD-0004의 흐름(템플릿 → 시작 방법 → 편집기)은 유지하되, 화면마다 정보와 선택지가 많았다.
- 헤더의 단계 표시와 버튼 화살표 같은 장식 요소가 많다.
- 쉽게 시작이 3단계에 결과 화면까지 있어 길다.
- 편집기에서 디자인(테마·레이아웃)까지 다루느라 사용자의 집중이 흩어진다.

**원칙: 디자인은 템플릿에서 끝낸다. 이후 단계는 정보 입력에만 집중한다.**

## 2. 결정
| # | 영역 | 결정 |
|---|---|---|
| D1 | 공통 | 헤더 우측의 단계 표시 삭제 |
| D2 | 공통 | 로고 `청첩장 메이커`는 **중앙 배치**, 어떤 단계(편집기 모바일 포함)에서도 사라지지 않음 → 공통 `AppHeader` 컴포넌트, sticky |
| D3 | 템플릿 | 템플릿 카드의 태그 칩(테마·레이아웃) 삭제 |
| D4 | 템플릿 | 하단 고정 버튼 `이 템플릿으로 시작하기`, 화살표 없음 (모든 고정 버튼 공통 규칙) |
| D5 | 시작 방법 | 선택한 템플릿 영역은 **썸네일 + 템플릿명만** (설명·"템플릿 바꾸기" 링크 삭제 → 헤더 `←`로 대체) |
| D6 | 시작 방법 | 쉽게 시작 설명: "기본 사진과 정보를 입력해서 간단하게 청첩장을 만들어요." |
| D7 | 시작 방법 | 카드 안의 `사진으로 시작하기 →`, `편집기 열기 →` 문구 삭제 (카드 전체가 버튼) |
| D8 | 쉽게 시작 | 3단계·결과 화면 삭제, **한 페이지**(이름·일시·장소·주소·사진) → `편집 시작하기` → 편집기 |
| D9 | 쉽게 시작 | 제목 "기본 정보를 입력해주세요", 설명 "비워둬도 괜찮아요. 편집기에서 채울 수 있어요." → 사진 포함 **모든 항목 선택** |
| D10 | 쉽게 시작 | 결과 화면이 사라지면서 "템플릿 색 / 사진에서 뽑은 색" 선택도 삭제 |
| D11 | 편집기 | 좌상단 ✕(모바일)·←(데스크탑) 제거 |
| D12 | 편집기 | **테마 패널 삭제** + 히어로 사진 배치·갤러리 보기 방식 선택도 삭제 (디자인 = 템플릿) |
| D13 | 편집기 | 용어 `문서 정보`·`정보` → **`기본 정보`** (데스크탑 목록·패널 제목, 모바일 툴바·시트, 안내 링크) |
| D14 | 편집기(모바일) | `구성` 시트에서 기본 정보 항목 제외(툴바에 별도 버튼이 있으므로) |

## 3. 판단 메모
- **D12 범위:** 요청은 "테마 정보 삭제"였고, 근거는 "디자인이 아니라 정보 입력에 집중"이었다. 같은 근거로 섹션 폼 안의 레이아웃 선택(히어로 full/frame/arch, 갤러리 grid/slide)도 디자인으로 보고 함께 뺐다. 히어로 헤드라인 문구는 내용이므로 유지했다.
- **D11 이후 이탈:** 편집기에 나가기 버튼이 없으므로 브라우저 뒤로가기가 유일한 이탈 경로다. 새로고침·탭 닫기는 `beforeunload`로 경고하지만, SPA 내 뒤로가기는 경고하지 않는다(내용 소실). 저장 기능 재도입 시 함께 해결한다.

## 4. 화면 요약
```
[템플릿]     ┌ 청첩장 메이커 ┐   카드: 미리보기 + 이름 + 한 줄 설명   [이 템플릿으로 시작하기]
[시작 방법]  ┌← 청첩장 메이커 ┐   [썸네일 | 클래식 액자]  카드: 쉽게 시작(추천) / 바로 편집
[쉽게 시작]  ┌← 청첩장 메이커 ┐   기본 정보를 입력해주세요 … 사진                [편집 시작하기]
[편집 데스크탑] ┌제목·저장 안 됨  청첩장 메이커  하객 화면 보기·공유하기┐
[편집 모바일]   ┌        청첩장 메이커         미리보기┐ … [☰구성 📋기본 정보 공유]
```

## 5. 열린 질문
- 편집기 안에서 템플릿(디자인) 바꾸기를 제공할지, 제공한다면 어디에서 할지
- 편집기 이탈 경로(뒤로가기) 경고 방식 — 저장 기능과 함께 결정

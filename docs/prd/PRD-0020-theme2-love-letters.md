# PRD-0020 2번 테마: 러브 레터

| 항목 | 내용 |
|---|---|
| 상태 | **확정 (스냅샷)** — 이 문서는 수정하지 않는다. 변경은 새 PRD로. |
| 작성일 | 2026-10-15 |
| 관련 헌법 | CONSTITUTION v0.77 (§3.5, §3.6, §4.1) |
| 대체 | 없음 (새 템플릿. 기존 2~6번 기본 계열 템플릿은 그대로 두고 목록 2번째에 추가) |
| 레퍼런스 | 사용자 제공 이미지: 흰 종이 위 하늘색 사각 면, 하트 모양으로 오린 사진, 둘레에 흩어진 빨간 동그라미, 동그라미 하나에 글자 하나씩 쓴 `LOVE LETTERS`, 아래 굵은 이름 |

---

## 1. 배경
1번 테마(모던 모노)를 마무리하고 두 번째 템플릿을 레퍼런스 이미지 기준으로 만든다. 사용자 결정:
1. 히어로 사진은 **원본 색 그대로**(흑백 필터 없음).
2. 동그라미 글자는 **영문 문구, 편집 가능**.
3. 글꼴 굵기 규칙 **400·500·600 유지**(레퍼런스의 아주 굵은 글꼴은 쓰지 않음).
4. 색은 **원톤**: 하늘색 면이 포인트 색을 따라 바뀌고, 레퍼런스의 빨간 동그라미는 같은 색의 **진한 명도**로 쓴다.

## 2. 결정
| # | 결정 | 이유 |
|---|---|---|
| D1 | 새 계열 `dots`(도트) + 팔레트 `sky` + 모양 `round`. 템플릿 id `love-letters` | 섹션 컴포넌트·토큰은 공용, 계열 CSS로 장식만 바꾼다(§3.6 구조 그대로) |
| D2 | **원톤 색**: 포인트(진한 파랑 `#3d63a8`)가 동그라미·제목·버튼. 하늘색 면 `--c-tint` = 포인트 34% + 흰색, 연한 섹션 바탕 `--c-tint-soft` = 포인트 13% + 바탕 | 결정 4. 포인트 색 바꾸기(PRD-0019) 하나로 면·동그라미가 함께 바뀜 |
| D3 | 히어로 레이아웃 `heart`: 위 작은 문구(헤드라인, 기본 `WEDDING INVITATION`) · 하늘색 면(20:23) · 하트 모양 사진(마스크) · 면 가장자리에 걸친 동그라미 11개 · 동그라미 글자 · 이름(`김민준 & 이서연`, 20 SemiBold) · 일시·장소 · 음악 바 | 레퍼런스 구성 |
| D4 | 동그라미 글자는 히어로 `script` 칸 재사용(기본 `OUR WEDDING`, 최대 16자, 대문자). 띄어쓰기로 줄을 나눠 최대 3줄, 줄마다 정해진 자리(왼쪽 위·오른쪽 가운데·왼쪽 아래), 글자는 물결처럼 위아래로 어긋남 | 결정 2. 새 데이터 없이 편집 가능 |
| D5 | 하트 장식 → **동그라미**: `HeartCut`이 하트와 동그라미를 함께 그리고, 도트 계열에서는 동그라미만 보인다(섹션 머리·예식일·방명록 쪽지 등) | 레퍼런스의 점 모티프로 통일, 섹션 코드 수정 없음 |
| D6 | 우리의 이야기·갤러리·방명록 섹션 바탕은 `--c-tint-soft`, 방명록 쪽지는 흰 종이 | 1번 테마의 연분홍 섹션과 같은 역할 |

## 3. 범위 밖
- 레퍼런스의 상단 브랜드 표기, 아주 굵은 글꼴.
- 동그라미·글자 움직임(애니메이션).

# PRD-0011 스티커를 최상단 레이어로 (섹션 크롭 해제)

| 항목 | 내용 |
|---|---|
| 상태 | **확정 (스냅샷)** — 이 문서는 수정하지 않는다. 변경은 새 PRD로. |
| 작성일 | 2026-10-13 |
| 관련 헌법 | CONSTITUTION v0.13 (§4.10) |
| 대체 | PRD-0009 D1 ("스티커는 섹션 밖으로 못 나감") |

---

## 1. 배경
PRD-0009에서 스티커는 각 섹션 안 레이어에 그려져 섹션 경계에서 잘렸다. 섹션 가장자리에 붙인 스티커가 반쯤 잘려 보여 **"섹션에 갇힌" 느낌**이 났다.

스티커 꾸미기의 맛은 **경계를 넘나드는 자유로움**(섹션 사이에 걸친 하트, 제목 옆으로 삐져나온 사진)에 있다. 그래서 스티커가 크롭에 먹히지 않게 한다.

## 2. 결정
| # | 결정 | 대안 | 이유 |
|---|---|---|---|
| D1 | 스티커를 **청첩장 최상단 오버레이 한 장**에 모아 그림 | 섹션마다 `overflow: visible` | 섹션의 등장 애니메이션(transform)이 쌓임 맥락을 만들어, 뒤에 오는 섹션이 스티커를 덮는 문제를 피할 수 없음 |
| D2 | 위치는 **여전히 섹션 기준 %** — 섹션의 레이아웃 위치를 재서 겹침 | 문서 전체 기준 좌표 | 섹션 순서 변경·숨김·내용 길이 변화에 스티커가 따라감(PRD-0009의 장점 유지) |
| D3 | 측정은 `offset*`(레이아웃 값) + `ResizeObserver` | `getBoundingClientRect` | 등장 애니메이션·템플릿 썸네일 축소(transform)의 영향을 받지 않음 |
| D4 | 중심 범위 4~96% → **0~100%** | 범위 무제한 | 스티커 절반까지 섹션 밖으로 걸칠 수 있게 하되, 어느 섹션 소속인지는 분명하게 |
| D5 | 청첩장 바깥 가장자리에서만 자름 | 자르지 않음 | 휴대폰 화면 가로 스크롤 방지 |
| D6 | 쌓임 순서: 섹션 < 위치 정하기 영역 < 스티커 < 편집 버튼 | 스티커 최상위 | 스티커가 [섹션 편집]/[붙이기] 버튼을 가리면 편집이 막힘 |
| D7 | 갤러리 라이트박스를 `body`로 포털 | 유지 | 최상단 스티커 레이어가 전체 화면 사진 보기 위로 올라오는 문제 방지 |
| D8 | 하객 화면에서 스티커도 화면에 들어올 때 나타남 | 항상 표시 | 섹션은 아직 안 나타났는데 스티커만 먼저 떠 있는 어색함 방지 |

## 3. 확인
- 시작 멘트 하단 경계에 붙인 스티커가 다음 섹션(신랑·신부) 위로 걸쳐 보임, 다음 섹션의 편집 버튼은 스티커 위에 표시
- 시작 멘트를 3칸 아래로 옮겨도 스티커가 섹션 하단 경계(100%)에 그대로 붙어 이동
- 섹션 숨김 시 스티커도 숨김, 다시 켜면 표시
- 375px에서 가로 스크롤 없음, 라이트박스는 `body` 아래에서 열림

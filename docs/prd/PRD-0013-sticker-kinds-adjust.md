# PRD-0013 스티커 종류 · 사진 조정 · 네모 프레임

| 항목 | 내용 |
|---|---|
| 상태 | **확정 (스냅샷)** — 이 문서는 수정하지 않는다. 변경은 새 PRD로. |
| 작성일 | 2026-10-13 |
| 관련 헌법 | CONSTITUTION v0.15 (§4.10) |
| 대체 | — (PRD-0012에 기능 추가) |

---

## 1. 배경
PRD-0012로 "바로 붙이고, 눌러서 꾸미기" 흐름이 정해졌다. 꾸미기 쪽에 세 가지가 부족했다.
- **프레임이 사진에 안 맞음:** 사진 구도와 프레임이 어긋나면 얼굴이 잘리거나 엉뚱한 부분만 보인다.
- **질감이 한 가지:** 모든 스티커가 그림자만 있는 같은 질감이라 다이어리 꾸미기 같은 아날로그 감성이 부족했다.
- **기본 모양 부족:** 기본적인 네모 프레임이 없었다.

## 2. 결정
| # | 결정 | 이유 |
|---|---|---|
| D1 | 프레임에 **네모**(모서리 살짝 둥근 정사각형) 추가, 순서 원·네모·하트·별·클로버 | 가장 기본적인 사진 모양 |
| D2 | 탭에 **종류** 추가: 기본·스티커·마스킹 테이프·골판지·폴라로이드 | 같은 사진도 재질에 따라 전혀 다른 분위기. 다꾸(다이어리 꾸미기) 감성 |
| D3 | 종류는 **프레임 모양을 따름**: 스티커 테두리·골판지 판 모두 선택한 모양대로, 폴라로이드만 카드 안에 모양 | 프레임 선택이 종류와 독립적으로 의미를 가짐 |
| D4 | 새 스티커 기본 종류 = **스티커**(흰 칼선) | "스티커 붙이기"라는 기능 이름과 가장 잘 맞음 |
| D5 | 선택 박스 테두리 아래 **[사진 조정]** 버튼 | 선택된 스티커에서만 노출, 위치(끌기)와 같은 맥락 |
| D6 | 사진 조정 에디터: 프레임 모양만 뚫린 **검은 dim** + 끌기 이동 + 핀치·휠·막대 확대(1~3배) | 프레임 밖이 어떻게 잘리는지 보이면서 조정 |
| D7 | 이동 범위 제한(사진이 항상 프레임을 덮음) | 프레임 안에 빈 공간이 생기는 실수 방지 |
| D8 | 조정값(`crop`)은 프레임·종류를 바꿔도 유지 | 다시 조정하지 않아도 됨 |
| D9 | 에디터는 `취소`로 변경 버림, `완료`로 반영 (꾸미기 탭은 즉시 반영과 구분) | 세밀한 조정은 실험이 많아 되돌릴 수 있어야 함 |

## 4. 구현 메모
- 사진은 프레임 박스 기준 cover 크기로 배치 후 `left/top = 50% + ox/oy`, `scale` 적용. 스티커 렌더와 에디터가 같은 계산을 쓴다.
- dim은 `mask-composite: exclude`로 "전체 − 프레임 모양"을 만든다.
- 테스트 중 발견: 바깥 래퍼 클래스 `kind-tape`가 테이프 조각 클래스와 겹쳐 스티커가 테이프 크기로 줄어드는 문제 → 래퍼는 `is-kind-*`로 분리.

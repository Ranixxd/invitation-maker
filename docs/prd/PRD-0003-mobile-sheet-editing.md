# PRD-0003 모바일 편집: 미리보기 우선 + 바텀시트

| 항목 | 내용 |
|---|---|
| 상태 | **확정 (스냅샷)** — 이 문서는 수정하지 않는다. 변경은 새 PRD로. |
| 작성일 | 2026-10-13 |
| 관련 헌법 | CONSTITUTION v0.3 (§6.1 개정, §6.5 신설) |
| 대체 | PRD-0001 D10 (모바일 편집기는 하단 탭 `구성/편집/미리보기`) |
| 참고 | Apple 초대장(Invites) 앱 — 전체 화면 초대장 위 `배경 편집` 버튼 → `배경 추가` 바텀시트 |

---

## 1. 배경
PRD-0001 D10은 모바일 편집기를 하단 탭 3개(구성/편집/미리보기)로 나눴다. 이 방식에는 세 가지 문제가 있다.
- 편집하면서 결과를 볼 수 없다. 탭을 오가야 한다.
- "어디를 고치고 있는지"를 머릿속으로 이어 붙여야 한다. 폼과 실제 화면이 분리되어 있다.
- 청첩장은 결국 스크롤해서 보는 결과물인데, 편집 경험이 그 형태와 다르다.

Apple 초대장 앱은 초대장을 전체 화면으로 보여주고, 고칠 부분 위에 `배경 편집` 같은 버튼을 띄운 뒤 바텀시트로 편집한다. 보는 화면이 곧 편집 화면이다.

## 2. 결정
| # | 결정 | 대안 | 이유 |
|---|---|---|---|
| D1 | 모바일 기본 화면을 **초대장 전체 화면 미리보기**로 | 탭 유지 | 결과물을 보면서 편집, 탭 전환 제거 |
| D2 | **화면 중앙선에 걸친 섹션 = 활성 섹션**, 그 위에 `[섹션] 편집` 버튼 | 섹션마다 상시 편집 아이콘 | 화면이 깔끔하고, 스크롤만으로 대상이 자연스럽게 바뀜 |
| D3 | 버튼은 섹션 내부에서 **sticky로 화면 중앙에 고정**, 섹션 경계에서 멈춤 | 섹션 정중앙 고정 | 히어로·달력처럼 긴 섹션에서도 버튼이 화면 밖으로 나가지 않음 |
| D4 | 편집은 **바텀시트**(내용 높이, 최대 88%) | 전체 화면 모달 | 뒤의 미리보기가 보여 변경 결과를 즉시 확인 |
| D5 | 시트 닫기: ✕ / 배경 탭 / Esc / 헤더 아래로 끌기(110px) | ✕만 | iOS 시트에 익숙한 제스처 |
| D6 | 섹션 순서·표시, 테마, 문서 정보는 **하단 플로팅 툴바**에서 각각 시트로 | 상단 메뉴 | 엄지 영역, 섹션과 무관한 전역 편집의 진입점 |
| D7 | 섹션 시트 상단에 `초대장에 표시` 토글 | 구성 시트에서만 | 보고 있는 섹션을 바로 숨길 수 있게 |
| D8 | 데스크탑(3단)·태블릿(2단)은 유지 | 전 기기 통일 | 넓은 화면에서는 폼과 미리보기를 나란히 두는 편이 효율적 |
| D9 | 미리보기 렌더러는 그대로 공유하고, `renderOverlay`·`autoScroll` 옵션만 추가 | 모바일 전용 렌더러 | WYSIWYG(§6.3) 유지 |

## 3. 화면 구성 (모바일)
```
┌───────────────────────────┐
│ (✕)      저장됨   [미리보기] │  ← 상단 플로팅 (반투명)
│                           │
│     초대장 전체 화면        │
│                           │
│     [ 날짜 편집 ]          │  ← 활성 섹션 위 중앙 알약 버튼
│                           │
│ [☰구성 🎨테마 📋정보 (공유)] │  ← 하단 플로팅 툴바
└───────────────────────────┘
   ↓ 버튼 탭
┌───────────────────────────┐
│     (미리보기 · 딤)         │
├────────── ─── ────────────┤
│          날짜          (✕) │  ← 끌어서 닫기
│ 초대장에 표시        [ON]  │
│ 일시 [2027-01-16 12:30]    │
│ 달력 보이기          [ON]  │
└───────────────────────────┘
```

## 4. 성공 기준
- 모바일에서 모든 섹션을 탭 전환 없이 편집할 수 있다.
- 편집 시트를 연 상태에서 변경 결과가 뒤의 미리보기에 즉시 보인다.
- 375px 폭에서 가로 스크롤이 생기지 않는다.

## 5. 열린 질문
- 갤러리처럼 시트 내용이 길 때, 시트를 반/전체 높이 두 단계로 둘지(현재 내용 높이, 최대 88%)
- 활성 섹션 점선 테두리를 유지할지
- 히어로 시트의 사진 선택을 Apple처럼 `사진 / 카메라` 큰 버튼과 추천 배경 갤러리 구성으로 바꿀지

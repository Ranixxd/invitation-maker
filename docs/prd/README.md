# PRD 스냅샷 보관소

설계 결정의 **히스토리**를 남기는 곳. 각 PRD는 작성 시점의 스냅샷이다.

## 규칙
1. 파일명: `PRD-XXXX-<kebab-제목>.md` (번호는 4자리, 순차 증가)
2. **작성 후 본문 수정 금지.** 설계가 바뀌면 새 PRD를 쓰고, 이전 PRD 상단 표의 `상태`를 `대체됨 → PRD-YYYY`(일부만 바뀌면 `일부 대체됨 → PRD-YYYY`)로만 바꾼다.
3. 현재 유효한 정책은 PRD가 아니라 [CONSTITUTION.md](../CONSTITUTION.md)에서 확인한다. PRD에서 확정된 내용은 헌법에 반영한다.

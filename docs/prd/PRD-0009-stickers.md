# PRD-0009 붙이기: 내 사진 스티커로 꾸미기

| 항목 | 내용 |
|---|---|
| 상태 | **일부 대체됨 → PRD-0010** (§2 사용자 흐름: 단계 분리), **PRD-0011** (D1 섹션 밖으로 못 나감) |
| 작성일 | 2026-10-13 |
| 관련 헌법 | CONSTITUTION v0.11 (§4.10 신설, §3.3, §6.5-3) |
| 대체 | — |

---

## 1. 배경
PRD-0005에서 디자인 편집(테마·레이아웃)을 빼고 템플릿에 맡겼다. 그 결과 사용자가 "내 청첩장답게" 손댈 여지는 문구와 사진 배치 정도만 남았다.

디자인 시스템을 깨지 않으면서 개성을 더할 수 있는 장치로, **내 사진을 스티커처럼 섹션 위에 붙이는 기능**을 추가한다. 꾸미기를 두 축으로 나눈다.
- **[섹션 편집]** — 내용(정보 입력)
- **[붙이기]** — 장식(내 사진 스티커)

## 2. 사용자 흐름
```
섹션에 도달 → [○○ 편집] [☺+ 붙이기]
                         │
   ① 사진·프레임  ──▶  ② 모션  ──▶  ③ 위치(섹션 안)  ──▶  ④ 완료
   새로 올리기/고르기     없음·뿅뿅·둥실      끌기 / 섹션 탭으로 이동      스티커가 붙음
   원·하트·별·클로버     빙글·두근·흔들      크기 작게·보통·크게
                                                         붙은 스티커 탭 → 수정 / 위치만 옮기기 / 떼기
```

## 3. 결정
| # | 결정 | 대안 | 이유 |
|---|---|---|---|
| D1 | 스티커는 **섹션 단위**로 붙고 그 섹션 밖으로 못 나감 | 페이지 전체 자유 배치 | 섹션 순서 변경·숨김과 함께 움직여야 함. 반응형에서 위치가 깨지지 않음 |
| D2 | 위치는 섹션 크기 대비 **%** 좌표, 크기는 섹션 너비 대비 % | px 좌표 | 기기 폭이 달라도 같은 자리 |
| D3 | 프레임은 **SVG 마스크**로 사진을 잘라냄 | 캔버스로 잘라 새 이미지 저장 | 원본 하나로 프레임을 자유롭게 바꿀 수 있음, 저장 용량 증가 없음 |
| D4 | 데이터는 `doc.stickers` 최상위 배열(`sectionId` 참조) | 섹션 data 안 | 어떤 섹션 타입이든 같은 방식. 섹션 data 타입을 건드리지 않음 |
| D5 | 섹션당 5개, 브랜드 소개 불가 | 무제한 | 과도한 장식으로 정보 가독성이 무너지는 것을 방지. 브랜드 영역 보호(§4.9) |
| D6 | 끌기는 스티커에서만, 섹션 탭으로도 이동 | 섹션 전체 드래그 | 모바일에서 긴 섹션을 스크롤할 수 있어야 함 |
| D7 | 하객 화면에서는 클릭 불가(장식) | 탭하면 확대 | 아래의 계좌 복사·지도 버튼 등을 가리면 안 됨 |
| D8 | 모바일은 [섹션 편집] 옆 버튼, 데스크탑은 패널 머리 버튼 + 휴대폰 미리보기에서 위치 | 데스크탑 별도 UI | 같은 훅(`useStickerFlow`)으로 흐름을 공유 |
| D9 | 사진 삭제 시 스티커 동반 삭제, 갤러리에서 뺄 때 스티커가 쓰는 사진은 보존 | — | 깨진 스티커가 남지 않게, 의도치 않은 스티커 소실 방지 |

## 4. 열린 질문
- 스티커 회전·자유 크기 조절(핀치) 지원 여부
- 프레임 테두리(흰 테두리, 색 테두리) 옵션
- 사진 외 기본 제공 스티커(꽃·리본 등) 라이브러리
- 스티커를 섹션 경계에 걸치게(반쯤 튀어나오게) 허용할지

# PRD-0012 붙이기: 바로 붙이고, 눌러서 꾸미기

| 항목 | 내용 |
|---|---|
| 상태 | **확정 (스냅샷)** — 이 문서는 수정하지 않는다. 변경은 새 PRD로. |
| 작성일 | 2026-10-13 |
| 관련 헌법 | CONSTITUTION v0.14 (§4.10) |
| 대체 | PRD-0010 전체 (사진 → 프레임 → 움직임 → 위치 단계 흐름) |

---

## 1. 배경
PRD-0010은 붙이기를 4단계(사진 → 프레임 → 움직임 → 위치)로 나눴다. 하지만 스티커는 **일단 붙여 놓고 보면서 다듬는** 성격의 기능이다. 붙이기 전에 프레임과 움직임을 미리 정하게 하면 결과를 상상하며 골라야 하고, 단계가 길어진다.

그래서 흐름을 **"붙이기"와 "꾸미기"로 분리**한다.

## 2. 결정
| # | 결정 | 이유 |
|---|---|---|
| D1 | `붙이기` → 사진 선택 창 → 고르는 즉시 **섹션 가운데에 붙음** | 결과가 바로 보임, 단계 0개 |
| D2 | 붙은 직후 **선택 상태** → 바로 끌어서 이동 | "붙이고 바로 옮긴다"는 자연스러운 다음 행동 |
| D3 | 기본값: 하트·뿅뿅·보통 | 가장 청첩장다운 조합으로 시작, 마음에 안 들면 바로 변경 |
| D4 | 붙은 스티커를 누르면 선택 → 하단 바 탭 **프레임·크기·움직임** | 꾸미기 옵션을 한 곳에, 탭으로 화면 높이 절약 |
| D5 | 옵션 버튼은 **내 사진이 적용된 미리보기**로 표시(움직임은 실제로 움직임) | 글자가 아니라 결과로 고름 |
| D6 | 모든 변경 **즉시 문서 반영**, 취소 없음, `완료`는 선택 해제 | 미리보기 = 결과. 되돌리려면 다시 바꾸면 됨. 상태 동기화 버그 원천 차단 |
| D7 | 선택된 동안 다른 스티커를 누르면 선택 전환 | 여러 스티커를 연달아 다듬기 |
| D8 | 단계 시트, 단계 표시, `사진 바꾸기`, `위치만 옮기기` 제거 | 선택 상태에서 모두 가능하거나(이동), 떼고 다시 붙이면 됨(사진) |
| D9 | 새로 붙일 때만 해당 섹션을 화면 가운데로 스크롤, 기존 스티커 선택 시 스크롤 없음 | 화면이 튀지 않게 |

## 3. 흐름
```
[붙이기] ─▶ (사진 선택 창) ─┬─ 취소 → 아무 일 없음
                            └─ 선택 → 섹션 가운데에 붙음 + 선택됨 ─ 끌어서 이동 ─ [완료]

붙은 스티커 탭 → 선택됨
  ┌──────────────────────────────────┐
  │  끌거나 섹션 안을 눌러 위치를 옮길 수 있어요  │
  │  [ 프레임 | 크기 | 움직임 ]             │
  │  (◯) (♡) (☆) (✤)   ← 내 사진 미리보기   │
  │  [떼기]                      [완료] │
  └──────────────────────────────────┘
```

## 4. 확인
- 모바일: 붙이기 → 사진 선택 → 시트 없이 바로 붙고 선택됨 → 별·크게·빙글 즉시 반영(연속 입력 포함) → 완료 → 다시 눌러 선택(프레임 탭) → 떼기
- 실제 마우스 끌기로 위치 이동 후 완료 시 위치 유지
- 데스크탑: 스티커 바가 휴대폰 미리보기 아래에 표시, 움직임 탭에서 두근 즉시 반영

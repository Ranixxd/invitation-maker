# PRD-0021 2번 테마: 크림 티켓 (러브 레터 대체)

| 항목 | 내용 |
|---|---|
| 상태 | **확정 (스냅샷)** — 이 문서는 수정하지 않는다. 변경은 새 PRD로. |
| 작성일 | 2026-10-15 |
| 관련 헌법 | CONSTITUTION v0.78 (§3.5, §3.6, §4.1, §8) |
| 대체 | PRD-0020(러브 레터) 전체. 계열 `dots`·팔레트 `sky`·히어로 `heart`·하트→동그라미 대체를 모두 걷어낸다 |
| 레퍼런스 | 사용자 제공 이미지(모바일 청첩장 세로 화면 모음): 사진 위 명조 이름과 날짜, 올리브 흐르는 띠, 핑크 재생 버튼 플레이어, 노란 우표 테두리 달력 티켓(앞뒤 하루 + 손으로 그린 동그라미 + 손글씨 메모), 세로 사진 2열, 찢은 모양 사진 + 핑크 점선, 시간 · 점 · 일정 세로 타임라인, 노란 면 |

---

## 1. 배경
러브 레터를 다듬던 중 사용자가 방향을 바꿔 "러브레터 스타일 드롭, 첨부한 사진과 같은 느낌으로" 요청. 이전 결정(사진 원본 색, 굵기 400~600, 포인트 색 바꾸기 유지)은 그대로 따른다.

## 2. 결정
| # | 결정 | 이유 |
|---|---|---|
| D1 | 새 계열 `ticket` + 팔레트 `cream` + 모양 `round`. 템플릿 id `cream-ticket`(목록 2번째) | 섹션 컴포넌트·토큰 공용, 계열 CSS로 모양만 바꾼다 |
| D2 | 색: 크림 바탕 `#fdf9ec` · 잉크 · **올리브 포인트 `#6b6f2f`**(띠·아이콘·선택). **핑크 `#f4c5c8`(버튼·재생)·노랑 `#f7eba0`(티켓·방명록 면)은 계열 고정 보조색** | 레퍼런스가 3색 조합. 포인트 색 바꾸기는 올리브만 바꾼다 |
| D3 | 글꼴: 제목·이름·숫자 **명조 Gowun Batang 400**(계열 display), 본문 Pretendard, `and`는 Great Vibes, 달력 메모는 한글 손글씨 **Nanum Pen Script**(SIL OFL, Google Fonts) | 레퍼런스의 세리프·손글씨 느낌을 한글로 |
| D4 | 히어로 `cover`: 꽉 찬 사진(9:14, 위아래만 잉크로 살짝 어둡게) 위 작은 문구(헤드라인, 기본 `WE'RE GETTING MARRIED`, 노랑) · 명조 이름 `김민준 and 이서연`(30) · 아래 양쪽 `01.16` / `2027` → 올리브 흐르는 띠(`음악을 켜고 함께 들어 주세요`) → 플레이어(가운데 핑크 원 재생 버튼 + 양옆 장식 아이콘 4개) | 레퍼런스 첫 화면 |
| D5 | 예식 일자 `ticket`: 노란 카드, 가장자리 반원 구멍(우표), 머리 `1월 16일 · 2027`, 앞뒤 하루씩 3칸(요일·명조 숫자, 칸 사이 선), 예식일은 **손으로 그린 핑크 동그라미 + 작은 하트**, 아래 손글씨 `이 날은 비워 두세요`. SAVE THE DATE 띠 없음 | 레퍼런스 달력 |
| D6 | 섹션 머리 하트 없음, 제목은 명조. 우리의 이야기는 리본 대신 **세로 타임라인**(날짜 · 선 위 점 · 내용). 갤러리는 테두리 없는 세로 사진 2열. 오시는 길 지도 자리는 **찢은 종이 모양**, 섹션 위아래 **핑크 점선 곡선**, 지도 버튼 핑크. 방명록은 노란 면 + 위 우표 가장자리, 쪽지는 흰 종이. 기본 버튼은 핑크 바탕 + 잉크 글자 | 레퍼런스 나머지 화면의 장치를 기존 섹션에 대응 |

## 3. 범위 밖
- 레퍼런스의 선 일러스트(식탁), 드레스 코드 섹션(기능 없음).
- 플레이어 양옆 아이콘의 실제 동작(장식).

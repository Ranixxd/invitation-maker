## 1. 배경
섹션별 피드백을 한 줄씩 반영하던 방식으로는 전체 그림이 맞지 않았다("새로 창조하는 수준"). 사용자가 Figma로 1번 테마 전체 초안을 그려 주었다. 사용자 메모:
1. 레드·블랙 두 가지 색만 쓰고 나머지는 불투명도를 낮춰 만들었다 → 나중에 **포인트 컬러(레드)만 바꾸는 기능**을 넣을 예정.
2. 좌우 여백 등 수치는 디테일하게 맞추지 않았다 → 효율적이고 일관되게 통일.
3. 우리의 이야기는 타임라인만.
4. 날짜 아래 SAVE THE DATE는 기존처럼 좌우로 흐르게.
5. 최대한 토큰·컴포넌트화.

## 3. 열린 질문
- Oblata Display 원본 폰트 파일 사용 가능 여부.
- 계좌 그룹 기본 펼침 여부(시안은 펼친 상태, 정책은 접힘 유지).
- 포인트 색 변경 기능의 UI(편집기 어디에, 프리셋 색 몇 개).

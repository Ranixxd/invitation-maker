# PRD-0014 데스크탑 붙이기: 타이틀 옆 버튼, 편집 패널 교체

| 항목 | 내용 |
|---|---|
| 상태 | **확정 (스냅샷)** — 이 문서는 수정하지 않는다. 변경은 새 PRD로. |
| 작성일 | 2026-10-13 |
| 관련 헌법 | CONSTITUTION v0.16 (§4.10) |
| 대체 | PRD-0012 D8의 데스크탑 부분(휴대폰 미리보기 아래 스티커 바) |

---

## 1. 배경
데스크탑에서 스티커 꾸미기 바가 오른쪽 휴대폰 미리보기 아래에 붙어 있었다. 두 가지 문제가 있었다.
- 가운데 편집 패널은 그대로라서, 지금 무엇을 편집 중인지(섹션 내용인지 스티커인지) 헷갈렸다.
- 넓은 화면에서도 모바일처럼 탭으로 한 종류씩 봐야 했다.
- 패널 머리의 `붙이기` 버튼은 아이콘 없이 오른쪽 끝에 있어 모바일과 모양이 달랐다.

## 2. 결정
| # | 결정 | 이유 |
|---|---|---|
| D1 | `붙이기` 버튼을 **타이틀 바로 옆**에, 모바일과 같은 아이콘으로 | "이 섹션에 붙인다"는 관계가 바로 보임, 기기 간 일관성 |
| D2 | 스티커 선택 시 **타이틀 아래 내용을 스티커 꾸미기로 교체** | 편집 대상이 하나로 명확. 패널 = 지금 편집 중인 것 |
| D3 | 타이틀은 스티커가 붙은 **섹션 이름** 유지 + `스티커 꾸미기` 배지 | 어느 섹션의 스티커인지 + 모드 구분 |
| D4 | 데스크탑은 탭 없이 **프레임·종류·크기·움직임을 모두 펼침**(자동 줄바꿈 그리드) | 넓은 화면에서는 한눈에 비교하는 편이 빠름 |
| D5 | 하단 버튼 `사진 조정`·`떼기`·**`붙이기 완료`** | 모바일 `완료`보다 무엇이 끝나는지 분명한 문구 |
| D6 | `붙이기 완료` 또는 목록에서 다른 항목을 고르면 선택 해제 → **원래 편집 정보로 복귀** | 모드에서 빠져나오는 길을 자연스럽게 |
| D7 | 휴대폰 미리보기 아래 바 제거, 대신 안내 문구만 "스티커를 끌거나 섹션 안을 눌러 위치를 옮길 수 있어요" | 꾸미기 UI는 패널 한 곳에만 |
| D8 | 스티커 선택 중에는 섹션 표시 스위치를 숨김 | 스티커 모드에서 섹션 숨김을 실수로 누르는 것 방지 |

## 3. 화면 (데스크탑)
```
┌ 섹션 목록 ┐┌ 갤러리 [☺+ 붙이기]          보이는 중 ◉ ┐┌ 휴대폰 미리보기 ┐
│          ││  (갤러리 편집 폼)                          ││               │
           ↓ 스티커 선택
┌ 섹션 목록 ┐┌ 갤러리 [스티커 꾸미기]                      ┐┌    ┌┄┄┐       ┐
│          ││ 오른쪽 미리보기에서 끌어서 위치를 옮길 수 있어요 ││    ┊♡ ┊       │
│          ││ 프레임  ◯ ▢ ♡ ☆ ✤                         ││    └┄┄┘       │
│          ││ 종류    기본 스티커 테이프 골판지 폴라로이드    ││  [사진 조정]   │
│          ││ 크기    작게 보통 크게                         ││               │
│          ││ 움직임  없음 뿅뿅 둥실 빙글 두근 흔들            ││               │
│          ││            [사진 조정] [떼기] [붙이기 완료]     ││               │
```

## 4. 구현 메모
- `useStickerFlow`가 옵션 버튼을 한 곳에서 만들고, 모바일용 `placementBar`(탭)와 데스크탑용 `panel`(전체 펼침)을 함께 내보낸다. 사진 조정 에디터는 `adjustEditor`로 분리.
- 훅 옵션 `onSelected`(데스크탑: 그 섹션 패널로 전환), `onAttached`(모바일: 섹션을 화면 가운데로 스크롤).
- 붙이기 아이콘은 `components/common/icons.tsx`의 `StickerPlusIcon`으로 공용화.

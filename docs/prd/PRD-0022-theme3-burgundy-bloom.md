# PRD-0022 3번 테마: 버건디 블룸

| 항목 | 내용 |
|---|---|
| 상태 | **확정 (스냅샷)** — 이 문서는 수정하지 않는다. 변경은 새 PRD로. |
| 작성일 | 2026-10-17 |
| 관련 헌법 | CONSTITUTION v0.85 (§3.5, §3.6, §4.4, §4.6, §8) |
| 레퍼런스 | 사용자 제공 이미지 2장. ① 아이보리 바탕 · 버건디 · 필기체 제목, 둥근 틀 사진 위에 걸친 필기체 이름, 자유롭게 그은 가는 선 좌우로 놓인 일정, 선 그림 백합, 위 가운데 반원 홈이 있는 버건디 테두리 카드 ② 하트 모양으로 흐르는 필기체 글자 앞에 가로로 놓인 사진 3장 |

---

## 1. 요청
템플릿 3 제작. ①에서: 히어로 사진이 처음엔 사각 틀 안에 있다가 스크롤할수록 넓어져 히어로를 꽉 채움 / 우리의 이야기는 자유롭고 얇게 그은 선 좌우로 배치 / 포인트 이미지는 꽃 / 방명록은 포인트색 테두리 카드. ②에서: 하트 모양으로 흐르는 텍스트 앞에 캐러셀 갤러리.

## 2. 결정
| # | 결정 | 이유 |
|---|---|---|
| D1 | 새 계열 `bloom` + 팔레트 `wine`(아이보리 `#fbf8f4` · 잉크 `#2b1d1f` · 버건디 포인트 `#7b1730`) + 모양 `round`. 템플릿 id `burgundy-bloom`, 이름 `템플릿3`(목록 3번째) | 섹션 컴포넌트·토큰 공용, 계열 CSS로 모양만 바꾼다. 색 구조는 1·2번과 같다(포인트 하나 + 잉크 + 바탕) |
| D2 | 글꼴: 섹션 제목·히어로 이름·이야기 날짜·방명록 이름은 **나눔손글씨 붓**(Nanum Brush Script, SIL OFL 1.1, Google Fonts), 나머지 Pretendard. 하트 글자 띠는 Great Vibes | 레퍼런스의 필기체 제목을 한글로. 웹폰트 사용이 허용되는 무료 글꼴 |
| D3 | 히어로 `unfold`(펼침): 히어로 높이 = 무대(스크롤 상자 높이, 폭의 1.4~2배) × 1.7. 무대가 위에 붙어 있는 동안 스크롤 진행도(0→1)에 따라 사진 틀이 위아래 22%·좌우 40px·라운드 16px에서 0으로 넓어진다. 붓글씨 이름 두 줄이 틀 위쪽에 비스듬히 걸치고(포인트색 → 펼치면 크림색), 틀 아래에 작은 문구·일시, 틀 아래 가장자리에 포인트 원 재생 버튼, 위 오른쪽·아래 왼쪽에 선 그림 백합(사진 뒤). 움직임 줄이기면 틀 그대로 고정 | 요청 1. 스크롤 상자를 찾아(편집기·미리보기 휴대폰 화면 / 창) 어디서나 같게 동작 |
| D4 | 우리의 이야기: 항목을 좌우 번갈아 왼쪽 정렬로 놓고, **가는(1px) 자유 곡선**이 항목 반대쪽 빈 칸을 지나 항목 사이마다 반대편으로 건너가며 고리를 하나씩 그린다(고리 크기·방향·자리를 조금씩 다르게). 날짜는 붓글씨 포인트색. 섹션 위 오른쪽에 백합. 섹션이 보이면 선이 그려진다 | 요청 2. 1번의 리본 선 장치(위치 측정·그리기 효과)를 재사용, 경로만 다르다 |
| D5 | 포인트 이미지 = **선 그림 백합**(`LilyDoodle`, 꽃잎 6·수술·줄기·잎, 굵기 1px 고정): 히어로 모서리 2곳, 우리의 이야기, 방명록 카드 모서리(포인트 20%) | 요청 3 |
| D6 | 방명록: 2열 카드 6개씩. 카드 = 흰 종이 + **포인트색 2px 테두리** + 라운드 12 + 위 가운데 반원 홈(레퍼런스 사진 틀 모양) + 오른쪽 아래 옅은 백합. 이름 붓글씨 포인트, 본문 4줄. 크게 보기 카드도 포인트 테두리 | 요청 4 |
| D7 | 갤러리 `carousel`: 하트 모양 길을 따라 `you have my heart ·`가 끝없이 흐르고(Great Vibes, 포인트 40%, 40초 한 바퀴, 이음매 없음), 그 앞에 가로로 넘기는 사진(4:5, 폭 58%, 가운데 맞춤, 가운데서 멀수록 작게, 처음엔 두 번째 사진이 가운데). 9장 모두, 더보기 없음. 하객 화면에서 누르면 라이트박스 | 요청 ② |
| D8 | 섹션 머리 표시(하트·꽃) 없음, 제목 붓글씨 잉크. 예식 일자는 `strip`을 계열 CSS로: 위아래 선 없음, 예식일은 **선으로 그린 하트**(채우지 않음) + 포인트 숫자, SAVE THE DATE 없음 | 레퍼런스 ①의 한 주 달력 |

## 3. 범위 밖
- 레퍼런스 ①의 사진 틀(버건디 테두리 + 홈) 갤러리, 겹쳐 흐르는 큰 필기체 제목, 요청 사항 카드 섹션(기능 없음).
- 레퍼런스 ②의 드레스 코드 색 칩.

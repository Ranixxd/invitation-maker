# PRD-0015 1번 테마: 웜 폴라로이드

| 항목 | 내용 |
|---|---|
| 상태 | **확정 (스냅샷, 초안)** — 이 문서는 수정하지 않는다. 변경은 새 PRD로. |
| 작성일 | 2026-10-13 |
| 관련 헌법 | CONSTITUTION v0.20 (§3.5, §8) |
| 대체 | PRD-0004 §4 템플릿 표의 1번(`classic-full` 클래식 풀스크린) |

---

## 1. 배경
지금까지 6개 템플릿은 색(프리셋)과 히어로·갤러리 배치만 다른 **임시 템플릿**이었다. 실제 판매할 테마 제작을 1번부터 시작한다.

1번 테마의 레퍼런스는 사용자가 공유한 러시아어 청첩장 시안이다. 키워드는 **감각적 · 모던 · 따뜻함**.
- 버터 크림 바탕에 흑백 사진, 짙은 갈색 글자
- 손글씨 캘리그래피 제목 + 단정한 명조 본문
- 기울어진 폴라로이드 사진, 곡선으로 휘어진 `wedding` 글자
- 굵은 콘덴스드 날짜, 얇은 선 꽃가지 장식
- 세로 연결선이 있는 하루 일정, 작은 토프색 버튼

## 2. 결정
| # | 결정 | 이유 |
|---|---|---|
| D1 | 1번 자리의 `classic-full`을 **`warm-polaroid`로 대체** | 사용자 요청("첫번째 테마 자리에"). 임시 템플릿은 순차 교체 |
| D2 | 새 프리셋 `warm`: 바탕 `#f8f3e5` · 카드 `#efe7d3` · 글자 `#2b2520` · 보조 `#857a6d` · 포인트 `#6d5e53` | 레퍼런스의 버터 크림·짙은 갈색·토프 버튼 |
| D3 | 섹션 제목 = **영문 손글씨(Great Vibes)** 크게 + 한글 명조 작은 제목 | 한글 손글씨 폰트는 장난스러워 레퍼런스의 캘리그래피 결과 다름. 영문 손글씨 + 한글 명조 조합이 감각적이면서 읽힘 |
| D4 | `WEDDING DAY`·날짜·폴라로이드 이름 = **Oswald**(콘덴스드) | 레퍼런스의 얇은 대문자 제목·굵은 날짜와 같은 결 |
| D5 | 새 히어로 레이아웃 **`polaroid`**: 기울기 −2.5°, 흰 여백, 사진 **흑백 처리**, 양옆 곡선 글자(SVG textPath) | 레퍼런스의 핵심 장면. 흑백 처리로 어떤 사진을 넣어도 톤이 통일됨 |
| D6 | 섹션 구분선 제거, 대신 **얇은 선 가지 장식**을 시작 멘트·오시는 길·방명록 뒤에 | 레퍼런스의 여백과 장식 리듬 |
| D7 | 추가 정보 타임라인을 **하루 일정표처럼**(가운데 정렬 + 세로 연결선) | 레퍼런스 "프로그램" 영역 표현을 우리 섹션에 이식 |
| D8 | 버튼은 꽉 찬 폭 대신 **가운데 작은 토프 버튼**, 카드는 평평한 크림·모서리 6px | 레퍼런스의 차분한 모던함 |
| D9 | 테마 고유 스타일은 `.inv--warm` 아래로만, 섹션 눈썹 글자 원문은 제목식(`Bride & Groom`), 기본 스타일이 대문자 변환 | 다른 테마는 그대로 두고 손글씨 테마만 자연스러운 대소문자 사용 |

## 3. 레퍼런스에 있으나 이번에 넣지 않은 것
- **드레스코드 섹션**(여성·남성 의상 사진 + 색상 칩): 섹션 구성(PRD-0008)에 없음. 필요하면 섹션 추가로 별도 결정
- **장소 사진**: 오시는 길에 사진 필드가 없음
- **러시아식 일정표 섹션**: 별도 "식순" 섹션 없음 → 추가 정보 타임라인으로 대체(D7)

## 4. 확인 (프로덕션 빌드, 375px)
- 템플릿 미리보기: 히어로(폴라로이드·곡선 글자·굵은 날짜) → Invitation(손글씨) + 가지 장식 → Bride & Groom → 타임라인 일정표 → RSVP 토프 버튼
- 편집기: 사진 없는 폴라로이드 빈 자리 안내, [대표 사진 편집]·[붙이기] 표시
- 다른 템플릿(모던 시네마): 눈썹 글자 대문자·기존 폰트 유지
- 폰트 로드(Great Vibes·Oswald) 확인

## 5. 열린 질문
- 곡선 글자의 배치(레퍼런스는 폴라로이드 위쪽 모서리를 감싸는 짧은 호 여러 줄) — 실제 사진을 넣고 다듬기
- 흑백 처리를 사용자가 끌 수 있게 할지(현재 테마 고정)
- 드레스코드 섹션 추가 여부

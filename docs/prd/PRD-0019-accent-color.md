# PRD-0019 포인트 색 바꾸기

| 항목 | 내용 |
|---|---|
| 상태 | **확정 (스냅샷)** — 이 문서는 수정하지 않는다. 변경은 새 PRD로. |
| 작성일 | 2026-10-14 |
| 관련 헌법 | CONSTITUTION v0.75 (§3.5, §3.6, §6.2) |
| 대체 | PRD-0005의 "디자인 편집 제거" 중 **색** 부분만(포인트 색 하나 예외). 테마·글꼴·레이아웃 편집 없음은 유지 |

---

## 1. 배경
PRD-0018에서 렌더러 색을 포인트·잉크·크림 3색에서만 파생하도록 만든 이유가 "나중에 포인트 컬러만 바꾸는 기능"이었다. 사용자가 지금 넣기를 요청했다(추천 색 + 직접 고르기 둘 다).

## 2. 결정
| # | 결정 | 이유 |
|---|---|---|
| D1 | 편집기에서 바꿀 수 있는 디자인 값은 **포인트 색(`doc.theme.accent`) 하나**. 위치는 `기본 정보` 패널 맨 위 `포인트 색`(데스크탑·모바일 공통) | 이미 저장되는 값이고 전체 색이 여기서 파생 → 새 데이터·렌더러 변경 없음. 정보 입력 흐름을 해치지 않는 최소 범위 |
| D2 | **추천 색 8개**(버건디·로즈·테라코타·브라운·세이지·네이비·라벤더·차콜) + 템플릿 기본색(목록에 없을 때 맨 앞) + **직접 고르기**(브라우저 색 선택기) | 대부분은 추천에서 고르고, 원하는 색이 있으면 직접 |
| D3 | 고른 색이 크림 글자와 대비 **4.5:1 미만**이면 그 이상이 될 때까지 **자동으로 어둡게** 저장하고 안내 문구를 보여준다(`readableAccent`) | 포인트 바탕 위 크림 글자(버튼·예식일 숫자)가 안 읽히는 청첩장이 발행되지 않도록. 추천 색은 모두 기준 이상 |
| D4 | 바꾼 색은 미리보기·발행본에 그대로 반영(문서 데이터) | 별도 처리 없음 |

## 3. 범위 밖
- 잉크·바탕(크림) 색 바꾸기, 글꼴·레이아웃 바꾸기.
- 템플릿 미리보기 화면에서 색 바꿔 보기.

# PRD-0016 1번 테마: 모던 모노

| 항목 | 내용 |
|---|---|
| 상태 | **확정 (스냅샷, 초안)** — 이 문서는 수정하지 않는다. 변경은 새 PRD로. |
| 작성일 | 2026-10-14 |
| 관련 헌법 | CONSTITUTION v0.22 (§3.5, §4.1, §8) |
| 대체 | PRD-0015 전체 (1번 테마 웜 폴라로이드) |

---

## 1. 배경
1번 테마 초안(웜 폴라로이드, PRD-0015)을 걷고, 사용자가 새로 공유한 레퍼런스의 **모던한 흑백 에디토리얼 스타일**로 1번 테마를 다시 잡는다.

레퍼런스(러시아어 전자 청첩장 시안)의 특징:
- 흑백 사진이 화면을 가득 채우는 히어로, 사진 위에 작은 날짜와 큰 이름
- 흰 바탕에 큰 대문자 고대비 세리프 제목(ЛОКАЦИЯ, ПРОГРАММА ДНЯ, ДЕТАЛИ)
- 3일짜리 달력 띠에 손으로 그린 붉은 하트로 예식일 표시, 그 아래 반복되는 `SAVE THE DATE`
- 어두운 사진 위 흰 카드로 된 장소 안내, 짙은 알약 버튼
- 가운데 정렬 하루 일정(`15:00 - WELCOME`), 붉은(버건디) 손글씨 포인트

## 2. 결정
| # | 결정 | 이유 |
|---|---|---|
| D1 | 1번 자리의 `warm-polaroid`를 **`modern-mono`(모던 모노)**로 교체, 웜 폴라로이드 관련 코드(프리셋 `warm`, 히어로 `polaroid`, 스타일, Great Vibes·Oswald 폰트)는 모두 제거 | "걷고" — 남겨둘 이유 없는 코드·폰트 로딩 제거 |
| D2 | 프리셋 `mono`: 흰 바탕 · 글자 `#151515` · 보조 `#6e6e6e` · 포인트 **버건디 `#8e1f2f`** | 레퍼런스의 흑백 + 붉은 포인트 |
| D3 | **모든 사진 흑백**(대표·갤러리·게스트 스냅·라이트박스) | 어떤 사진을 넣어도 레퍼런스 톤이 유지됨 |
| D4 | 섹션 제목 = 고대비 명조 **Nanum Myeongjo** 800, 본문 = 산세리프 | 레퍼런스의 큰 세리프 제목 + 작은 산세리프 본문 대비. 한글만(헌법 §3.5) |
| D5 | 히어로는 기존 `full` 레이아웃을 테마 스타일로: 작은 날짜(넓은 자간) **위에** 큰 이름, 헤드라인 없음 | 레퍼런스 첫 화면 그대로. 새 레이아웃 없이 CSS로 해결 |
| D6 | 예식 일자에 **표시 방식 `strip`** 신설(앞날·예식일·다음날 3칸 + 손그림 버건디 하트 + 흐르는 `SAVE THE DATE` 두 줄), 템플릿 값 `calendarStyle`로 선택 | 레퍼런스의 상징적 장면. 다른 템플릿도 쓸 수 있게 템플릿 값으로 일반화 |
| D7 | `SAVE THE DATE`는 영문이지만 **장식 문구**로 허용 | 섹션 제목이 아님(헌법 §3.5 영문 규칙에 예외로 명시) |
| D8 | 오시는 길: 짙은 바탕 위 **흰 카드**, 지도 버튼 짙은 알약 | 레퍼런스 "ЛОКАЦИЯ" 카드. 장소 사진 필드가 없어 사진 대신 짙은 바탕 |
| D9 | 타임라인은 가운데 정렬 일정표(날짜 굵게 + 내용 작게), 버튼은 짙은 알약, 카드·입력칸은 각진 모서리 | 레퍼런스 "ПРОГРАММА ДНЯ"와 전체적인 각진 에디토리얼 감각 |
| D10 | 섹션 기본 제목 한글화(`Gallery` → `갤러리`, `Guest Snap` → `게스트 스냅`) | 검토 중 발견: 영문 보조 제목은 지웠지만 기본 제목 데이터에 영문이 남아 있었음 |

## 3. 레퍼런스에 있으나 넣지 않은 것
- **드레스코드 섹션**(Black Tie 일러스트, 흐르는 `dress code` 손글씨): 섹션 구성에 없음
- **섹션 사이 흑백 사진 띠**(손 잡는 사진 등): 사진을 넣을 섹션이 없음 — 갤러리로 대체
- **장소 배경 사진**: 오시는 길에 사진 필드 없음 → 짙은 바탕으로 대체

## 4. 확인 (프로덕션 빌드, 375px)
- 템플릿 미리보기: 흑백 히어로(날짜 위·큰 이름) → 고대비 명조 제목 → 3일 띠(16일에 버건디 하트) + SAVE THE DATE 두 줄 → 흑백 갤러리 → 짙은 바탕 흰 카드 오시는 길
- 편집기: 사진 없는 히어로에서 그라데이션이 꺼져 이름이 읽힘(검토 중 발견해 수정)
- 다른 템플릿(클래식 액자)은 월 달력·기존 스타일 유지, 콘솔 에러 없음

## 5. 열린 질문
- 섹션 사이 흑백 사진 띠(레퍼런스의 중간 사진)를 갤러리 사진으로 자동 배치할지
- 장소 사진 필드 추가 여부(오시는 길 카드 배경)
- 드레스코드 섹션 추가 여부

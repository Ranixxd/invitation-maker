# PRD-0007 템플릿 미리보기 화면 · 갤러리 항상 표시

| 항목 | 내용 |
|---|---|
| 상태 | **확정 (스냅샷)** — 이 문서는 수정하지 않는다. 변경은 새 PRD로. |
| 작성일 | 2026-10-13 |
| 관련 헌법 | CONSTITUTION v0.7 (§1.2, 제2장, §3.5, §4.6 신설, §5.4, §5.5) |
| 대체 | PRD-0004 D8 중 목록 선택 상태(`?selected`) 방식, 목록 하단 시작 버튼 |

---

## 1. 배경
- **템플릿 선택:** 목록의 작은 썸네일(첫 화면 일부)만 보고 템플릿을 골라야 했다. 청첩장은 세로로 긴 문서라 아래쪽 섹션(갤러리·혼주·오시는 길 등)이 어떻게 생겼는지 모른 채 결정하게 된다.
- **갤러리:** 사용자가 "청첩장 구성에 갤러리(사진 모음집)를 추가해 달라"고 요청했다. 갤러리 섹션은 이미 있었는데, 원인을 보니 다음과 같았다.
  - 쉽게 시작에서 사진을 올리지 않으면 갤러리가 **자동으로 숨김** 처리됐다(PRD-0001 §5.4 규칙).
  - 모바일 편집기는 숨긴 섹션을 미리보기에 그리지 않는다.
  - 결과적으로 "갤러리가 없다"고 보였다.

## 2. 결정
| # | 결정 | 대안 | 이유 |
|---|---|---|---|
| D1 | 템플릿 카드 클릭 → **미리보기 화면**(`/templates/<id>`) | 목록 안 모달 | URL이 생겨 뒤로가기·공유가 자연스럽고, 모바일에서 전체 화면 스크롤이 편함 |
| D2 | `이 템플릿으로 시작하기`는 **미리보기 화면에만** | 목록·미리보기 양쪽 | 보고 나서 고르게 유도. 목록은 탐색 전용 |
| D3 | 미리보기는 **하객 화면 모드**로 렌더(등장 애니메이션·라이트박스 포함) | 편집 미리보기 모드 | 실제 하객 경험 그대로 확인 |
| D4 | 샘플 청첩장은 **모든 섹션이 채워진 상태**(샘플 사진 7장, 부모님, 장소, 교통편, 계좌) | 이름·날짜만 | 빈 섹션은 템플릿 느낌을 전달하지 못함 |
| D5 | 시작 방법 화면의 `←`는 해당 템플릿 미리보기로 | 목록으로 | 직전 화면으로 돌아가는 것이 자연스러움 |
| D6 | **갤러리는 사진이 없어도 자동 숨김하지 않음** | 기존 유지 | 구성에서 갤러리가 사라진 것처럼 보이는 문제 해결 |
| D7 | 빈 갤러리: 편집기에서는 빈 칸 6개 + 안내, **하객 화면에서는 그리지 않음** | 하객 화면에도 빈 칸 | 하객에게 빈 영역을 보여줄 이유 없음 |

## 3. 화면
```
/templates            /templates/romantic-arch                       /start?template=romantic-arch
┌ 청첩장 메이커 ┐      ┌← 청첩장 메이커 ┐                                ┌← 청첩장 메이커 ┐
[카드][카드]   ─클릭→  로맨틱 아치      ┌──────────┐                   어떻게 시작할까요?
[카드][카드]           아치형 사진과…   │ 샘플 청첩장 │ (스크롤)            …
                                       └──────────┘
                       [ 이 템플릿으로 시작하기 ]  ───────────────────▶
```
- 데스크탑: 왼쪽에 템플릿 이름·설명(고정), 오른쪽에 휴대폰 프레임
- 모바일: 이름·설명 아래로 프레임 없이 전체 폭 미리보기, 하단 고정 버튼

## 4. 열린 질문
- 미리보기에서 "내 사진으로 미리보기"(사진을 올려 바로 대입)를 제공할지
- 템플릿이 늘어나면 목록에 분류·필터가 필요할지

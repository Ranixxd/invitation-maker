# PRD-0017 템플릿 디자인 시스템 · 방명록 쪽지 보드

| 항목 | 내용 |
|---|---|
| 상태 | **일부 대체됨 → PRD-0018** (스냅샷) — 이 문서는 수정하지 않는다. 변경은 새 PRD로. |
| 작성일 | 2026-10-14 |
| 관련 헌법 | CONSTITUTION v0.23 (§3.5, §3.6, §4.4, §8) |
| 대체 | PRD-0016 일부 (D3 히어로 흑백, D4 명조 제목, 각진 카드·입력칸) |

---

## 1. 배경
1번 테마(모던 모노) 초안에 대한 사용자 피드백:
1. 히어로의 검정 필터를 빼고 사진의 원본 색감을 살린다.
2. 섹션 제목은 예식 일자의 날짜·시간 줄(`2027년 1월 16일 토요일 오후 12시 30분`)과 같은 크기로.
3. 방명록은 남겨진 것을 먼저 보여주고, 섹션에 도달하면 하단 떠 있는 `남기기` 버튼으로만 작성.
4. 레퍼런스(LOVE NOTE 종이 카드, 편지 카드 + 붉은 서명)처럼 **종이 쪽지가 보드 위에 놓인 형태**로 9개씩.
5. 버튼 등 UI는 **알약(라운드 최대)**.
6. 템플릿 **디자인 시스템**을 만들어 색 구성만 바꿔 재활용. 이번은 라운드 타입, 스퀘어 타입도 생길 수 있음.
7. (추가) 전체 폰트는 레퍼런스처럼 **얇고 세련된 고딕**.

## 2. 결정
| # | 결정 | 이유 |
|---|---|---|
| D1 | 템플릿 = **계열(family) + 팔레트(palette) + 모양(shape)**. 계열 CSS(`.inv--fam-<family>`)는 색·라운드·글꼴을 **토큰(`--inv-*`)으로만** 쓴다 | 같은 계열에 팔레트만 바꾸면 새 템플릿. 하드코딩 색이 있으면 재활용 불가 |
| D2 | 팔레트 토큰: bg·surface·text·muted·accent + **band**(짙은 띠)·**onBand**(띠 위 카드)·**paper**(쪽지)·**board**(보드) | 모던 모노에서 하드코딩하던 색을 모두 토큰화 |
| D3 | 모양 토큰 `round`(control 999px 알약 · card 22px · paper 6px · media 14px) / `square`(모두 0) | 라운드/스퀘어 두 타입을 같은 CSS로 |
| D4 | 계열 `basic`(기존 5종) / `editorial`(모던 모노). `mono` 전용 CSS는 `editorial` 계열로 이전 | 1번 테마 스타일을 다른 팔레트로 재사용 가능하게 |
| D5 | 히어로: 그라데이션·흑백 필터 제거, 글자 그림자로만 가독성. 갤러리·스냅은 흑백 유지 | 요청 1. 갤러리 흑백은 요청 범위 밖이라 유지 |
| D6 | 섹션 제목 18px(예식 일자 날짜 줄과 동일), 굵기 500 | 요청 2 + 얇은 고딕 톤 |
| D7 | editorial 글꼴: 제목·본문 모두 **Noto Sans KR 300~500**, 명조(Nanum Myeongjo) 제거. 쪽지 서명만 손글씨(Nanum Pen Script) 포인트색 | 요청 7. 레퍼런스도 고딕 본문 + 붉은 필기체 서명 |
| D8 | 방명록: 보드(`board`) 위 종이(`paper`) 쪽지 3×3 = **9개씩** + 페이지 번호. 쪽지는 id 기반 일정한 기울기, 일부 클립. 받는 사람·본문(3줄)·서명 | 요청 4 |
| D9 | 쪽지를 누르면 크게 보기(보내는 사람·받는 사람·본문·서명·남긴 날) | 3줄로 잘린 본문 전체 확인 |
| D10 | 작성은 `남기기` 버튼 → 작성 모달에서만. 하객 화면(`/view`)은 섹션이 보이는 동안 하단에 떠 있는 버튼, 편집기·템플릿 미리보기는 섹션 안 버튼 | 요청 3. 편집기 미리보기 안에서 fixed 버튼은 편집 UI와 겹침 |
| D11 | 정렬: 내가 남긴 것(최신순) → 예시 쪽지. 샘플 청첩장에 예시 쪽지 11개(`GuestbookData.seed`, 미리보기 전용) | "남겨진 걸 먼저", 9개 단위 넘김이 미리보기에서 보이도록 |
| D12 | 포털(모달·떠 있는 버튼)은 `ThemePortal`로 같은 토큰·계열 클래스를 다시 입힌다 | 렌더러 루트 밖이라 변수 상속이 끊김 |

## 3. 새 템플릿 만드는 법 (디자인 시스템 사용)
1. `templates.ts` `THEME_PRESETS`에 팔레트 1개 추가(10개 색 토큰 + 기본 글꼴).
2. `designTemplates.ts`에 템플릿 추가: `preset`(새 팔레트) + `family`(예: `editorial`) + `shape`(`round`/`square`).
3. CSS 추가 없음. 계열 고유 표현이 새로 필요할 때만 `.inv--fam-<family>`에 토큰으로 작성.

## 4. 열린 질문
- 스퀘어 타입 첫 템플릿의 팔레트·이름.
- 서버 도입 시 방명록 정렬(최신/오래된), 비밀글·삭제(§4.4).
